# Listly

Listly - Android-приложение для поиска фильмов, сериалов, аниме и игр. В приложении можно добавлять медиапозиции в личный список, отмечать статус просмотра, добавлять в избранное и распределять элементы по папкам.

## Возможности

- Регистрация и вход в аккаунт.
- Поиск медиапозиций в общем каталоге.
- Детальный экран медиапозиции.
- Добавление элемента в личный список.
- Статусы: запланировано, в процессе, завершено, брошено.
- Избранное, пользовательская заметка и оценка.
- Папки для группировки элементов.
- Экран "Мои списки" с фильтрацией и сортировкой.
- Светлая и тёмная тема.

## Установка APK

Для обычного запуска приложения Java и Android Studio не нужны.

1. Скачайте APK-файл из раздела GitHub Releases.
2. Скопируйте APK на Android-устройство или откройте его сразу на устройстве.
3. Если Android попросит разрешение, включите установку приложений из неизвестных источников для браузера или файлового менеджера.
4. Установите приложение и запустите Listly.

Минимальная версия Android: Android 10, API 29.

Для работы приложения нужен интернет, потому что каталог, аккаунт и пользовательские списки загружаются с backend API.

## Backend

По умолчанию приложение подключается к серверу:

```text
http://158.160.251.150:8080
```

Основные API-разделы:

- `POST /auth/register` - регистрация.
- `POST /auth/login` - вход.
- `GET /media/search` - поиск по каталогу.
- `GET /media/{id}` - данные конкретной медиапозиции.
- `GET /user-media` - пользовательский список.
- `POST /user-media` - добавление в список.
- `PATCH /user-media/{id}` - изменение пользовательских данных.
- `DELETE /user-media/{id}` - удаление из списка.
- `GET /folders`, `POST /folders`, `PATCH /folders/{id}`, `DELETE /folders/{id}` - папки.

## Сборка из исходников

Этот раздел нужен только если вы хотите открыть проект в Android Studio или собрать APK самостоятельно.

Требования:

- Android Studio с Android SDK.
- JDK 17.
- Интернет для загрузки Gradle-зависимостей.

Проект использует:

- Kotlin 2.2.21.
- Android Gradle Plugin 8.13.0.
- Jetpack Compose.
- Navigation 3.
- ELM/Elmslie.
- Dagger.
- OkHttp.

Открытие проекта:

1. Клонируйте репозиторий.
2. Откройте папку проекта в Android Studio.
3. Дождитесь Gradle Sync.
4. Запустите конфигурацию `app` на эмуляторе или физическом устройстве.

Сборка debug APK из терминала Windows:

```powershell
.\gradlew.bat assembleDebug
```

Готовый debug APK появится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Запуск unit-тестов:

```powershell
.\gradlew.bat testDebugUnitTest
```

## Проверка после установки

1. Запустите приложение.
2. Зарегистрируйтесь или войдите в существующий аккаунт.
3. Откройте каталог и выполните поиск.
4. Откройте медиапозицию.
5. Добавьте её в список.
6. Проверьте, что элемент появился во вкладке "Мои списки".
7. Попробуйте изменить статус, избранное, папку, заметку или оценку.

Если авторизация работает, но каталог или списки не загружаются, сначала проверьте интернет и доступность backend-сервера.
