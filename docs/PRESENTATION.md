# Презентация к защите Listly

## Слайд 1. Название проекта

**Listly** - Android-приложение для поиска медиаконтента и ведения личного readlist.

## Слайд 2. Цель проекта

Сделать мобильный клиент, в котором пользователь может:

- авторизоваться;
- искать фильмы, сериалы, аниме и игры;
- добавлять позиции в readlist;
- распределять позиции по папкам;
- фильтровать и сортировать свою коллекцию.

## Слайд 3. Итоговый результат

Реализованы:

- auth-сценарии;
- каталог с поиском;
- readlist;
- папки;
- настройки;
- детальный экран;
- интеграция с backend API.

## Слайд 8. Demo-сценарий

Короткий сценарий показа:

1. Войти или зарегистрироваться.
2. Найти медиапозицию в каталоге.
3. Добавить ее в readlist и выбрать папку.
4. Открыть readlist.
5. Проверить фильтры и сортировку.
6. Открыть настройки и управление папками.
